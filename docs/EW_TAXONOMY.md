# EW Taxonomy

## Electronic Warfare Classification

EW-Verify maps every scenario to an Electronic Warfare taxonomy category:

| Category | Code | Description |
|----------|------|-------------|
| Electronic Attack | EA | Offensive use of electromagnetic energy |
| Electronic Protect | EP | Defensive measures against EW |
| Electronic Support | ES | Intelligence gathering via EM spectrum |
